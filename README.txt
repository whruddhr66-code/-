Japanese Pop! 웹앱 배포 안내

파일
- index.html: 일본어 학습 앱
- manifest.webmanifest: 홈 화면 설치 설정
- sw.js: 기본 오프라인 캐시
- icon.svg: 앱 아이콘

무료 배포 예시: GitHub Pages
1. GitHub에서 새 저장소(repository)를 만듭니다.
2. 이 폴더의 파일 4개를 저장소 최상위에 업로드합니다.
3. Settings → Pages → Deploy from a branch를 선택합니다.
4. main 브랜치와 /(root)를 선택하고 저장합니다.
5. 생성된 HTTPS 주소를 스마트폰과 태블릿에서 엽니다.

홈 화면 추가
- Android/Chrome: 메뉴 → 앱 설치 또는 홈 화면에 추가
- iPhone/iPad/Safari: 공유 메뉴 → 홈 화면에 추가

주의
- 설치 및 오프라인 캐시는 HTTPS 주소에서 작동합니다.
- 학습 기록은 기기/브라우저별로 저장됩니다. 여러 기기 간 동기화 및 로그인은 포함되어 있지 않습니다.
- 일본어 음성은 기기 브라우저의 일본어 음성 지원 여부에 따라 달라질 수 있습니다.
- 현재 학습 콘텐츠는 입문용 시제품이며, 일본어 정규 교재 전체를 대체하지 않습니다.
